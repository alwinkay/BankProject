# Banking Application (Java Console App)

A simple Java-based banking application built to practice core Java concepts, object-oriented programming, and basic security logic.  
This project simulates real-world banking operations through a console interface.

---

## Features

- Create a bank account with a 4-digit PIN
- PIN authentication with a maximum of 3 attempts
- Deposit money
- Withdraw money
- Check account balance
- Exit the application safely

---

## Security Features

- PIN-based authentication
- Account lockout after 3 incorrect PIN attempts
- Encapsulation of sensitive data (balance and PIN)

---

## Concepts Practiced

- Object-Oriented Programming (OOP)
    - Classes and Objects
    - Constructors
    - Encapsulation
- Control flow (loops and conditionals)
- User input handling using Scanner
- Basic authentication logic
- Clean and readable code structure

## Technologies Used
